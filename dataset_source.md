# Dataset Source

## File Name
`part_1_ecommerce_customer_segmentation.csv`

## Source
Provided as part of the Business Analysis / Data Analysis Project — Part 1.

**Dataset Folder:** [Google Drive Link](https://drive.google.com/drive/folders/1XC-00liRViTlyeFaig3mYTkQcBrheph6?usp=sharing)

## Description
This is a transaction-level e-commerce dataset containing purchase records from an online retail store. Each row represents a single line item in a customer invoice.

## Dataset Details
| Property | Value |
|---|---|
| File format | CSV |
| Raw rows | 4,395 |
| Columns | 9 |
| Unique customers (raw) | 692 |
| Unique invoices | 1,450 |
| Countries | 11 |
| Product categories | 11 |
| Date range | January 2025 – November 2025 |

## Columns
| Column | Type | Description |
|---|---|---|
| InvoiceNo | String | Unique invoice/transaction ID |
| StockCode | String | Unique product code |
| Description | String | Product name |
| Category | String | Product category |
| Quantity | Integer | Units purchased |
| InvoiceDate | DateTime | Date and time of transaction |
| UnitPrice | Float | Price per unit (£) |
| CustomerID | String | Unique customer ID |
| Country | String | Customer country |

## Usage
Only the dataset provided for Part 1 was used in this project. No external datasets were combined or added.
